This is ADR-0065 item D (§3, field kinds). It follows C.

- **`policy/registry/lifecycle_status.yaml`** is a seed and generic. It takes IEC 62402 and EIA-724 wording: `active`, `not-recommended-for-new-design`, `last-time-buy`, `obsolete`, `unknown`. A deployment overlay extends it.
  - Values are validated as plain strings against the served registry, the same pattern as review shapes. They are never an OpenAPI enum.
- **`lifecycle_status {status, source, as_of, successor?}`** is emitted by Lane 1's disposition writer, in the same transaction as the PCN rule match (ruled 2026-11-06).
  - **Status absent means not assessed. Status null means assessed, and none known.** Readers and writers keep the two apart, and a seal checks it.
- **`ltb_decision {quantity, by, rationale, approved_by}`** is the action record of a last-time-buy resolution. ADR-0065 left its four fields undefined until this item, so D defines them.
