# Board

The cross-lane board answers "where is everything". Items are files, priorities are data,
and `BOARD.md` is generated by `scripts/render_board.py` and never edited.

- `items/<ULID>.md`: one item per file; `python scripts/render_board.py --new-id` makes the id.
- `PRIORITIES.md`: features (rank, slug, name), item priorities (table order is the sort order), reorders log.
- `SWEEP.md`: `swept_at:` timestamp (or empty) and a `| item | flag |` table. Flags are shown, never corrected.

## Item frontmatter

Exactly these ten keys, `key: value`, one per line.

- `title` non-empty. `feature` a slug from PRIORITIES. `repo` a slug.
- `lane` is `<repo>/<branch>`; empty only when `status: open`.
- `status` is open, claimed, blocked, review or done. `priority` is a value from PRIORITIES.
- `blocked_on` is a flow list of item ULIDs or `chris:<what>`; non-empty if and only if blocked; no commas in entries.
- `pr` is a flow list of `<repo>#<n>`; at least one when `status: review`.
- `ruling_ref` is free text. `updated` is `YYYY-MM-DD`.
- The body after the frontmatter must be non-empty.

## Commands

- `python scripts/render_board.py`: validate and write `BOARD.md` (exit 2 lists every error).
- `python scripts/render_board.py --check`: exit 1 with `DRIFT` if `BOARD.md` is stale (CI runs this).
