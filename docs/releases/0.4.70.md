## What changed

The full list is in `helm/invincible-agent/CHANGELOG.md` under 0.4.70. It carries every master merge since 0.4.69 (`7a45a3cb`): #93, #100, #97, #99, #96, #106, #105, #104, #109, #102, #103 and #110. Unlike 0.4.69, this release is an image roll: the sandbox moved from `867813be` to `b59e4a0f`.

- **Chart:**
  - #110: every public client gets an `audience-self` mapper;
  - #100: cortex-ui's redirect readback compares sets.
- **Release pipeline:** #93. The release needs the image build, and a missing image is fatal.
- **Images:**
  - cortex-bff carries #97, #99, #104, #103 and #96;
  - presentation-agent carries #105.
  - Every other iagent image is rebuilt at the same commit, since `global.imageTag` is one knob for the fleet.
- **Schema:** `ingest_status_projection.force_text_fallback`, which cortex-bff adds on startup.
